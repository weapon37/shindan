## 2. 書き方ルール
| # | ルール |
|---|---|
| 1 | 複数段のスレッド投稿。基本3段、長ければ4段。2段投稿も可（1段目＝言い切らない短いフック、2段目＝端的に） |
| 2 | 答えは次の段の冒頭で出す。1段目で言い切らない。1段目の末尾は「、」で終える（「。」で言い切らない） |
| 3 | 冒頭は話し言葉で、説明から入らない。1行目は毎回変える。数字か意外性、または読者の悩みから |
| 4 | 本文に「誰に向けてか」が分かる一言を入れる |
| 5 | フックの前に悩み・ベネフィットを置く。実績の言い回しを強める（「3時間半切ったことのある」「20年以上」） |
| 6 | 〇×形式: ×を1段目、末尾「代わりにやってることは、」、〇を2段目 |
| 7 | 絵文字（🙅🙆⭕）の行は絵文字だけの単独行にし、下は「・」の箇条書き。リスト型は先頭行にだけ絵文字 |
| 8 | ランキングは3位→2位→1位で、1位を最後に置く |
| 9 | 2段目は改行で区切る。初心者が真似できる入口の一言を足す |
| 10 | 締めは「〜してみよう」「教えてください」など柔らかい行動指示 |
| 11 | フックは不自然な言い切りで引っ張らない。「読者が読んだあとに得られるメリット」を考える |
| 12 | 使う型: 実績×ギャップ×答え隠し（勝ち型）、「数字＋得」、「〜な人へ」、「 」で始まるセリフ |
| 13 | 使わない型: 告白型（「正直に言います」「批判覚悟で」）。10/25のデータで伸びず、しばらく不使用 |
| 14 | フック10の型（`docs/runtan-until-1026/hook-10-types.md`）とお手本（`model-posts.md`）を参考にする。お手本の効果の言い切りは、まねしない |
| 15 | 出す前に、教材ワークブック「⑦投稿前チェックリスト」14項目を満たす（本人のGoogleスプレッドシート。リンク関連のNo.7・8・9・13は提携後に適用）。中身はリポジトリ内になく、不明 |

## 4. アフィリエイト・PR
| # | ルール |
|---|---|
| 1 | リンクはリプ欄（続きの段）かプロフィール。本文に直貼りしない |
| 2 | リンクを付けるのは基本1日2ネタ（2ツリー）まで。1ツリー＝1本で、その中の2段目・3段目に連投でリンクを貼る場合もある（ユーザー確認済み。ツリー内のリンク本数は問わない） |
| 3 | #PR必須。本文に「#」付きで表示されていることまで確認する |

| 5 | 公開直後チェック: ①全段が出ているか ②最終段にリンクがあるか ③#PRが「#」付きで表示か ④リンクURLが正しい商品ページか。本人に報告 |
| 6 | 予約の続き段欠落が3回発生済み。上のチェックを徹底。一群が終わるタイミングでまとめて分析・報告（第1回は11/8 22:15予定） |
| 7 | プレビューカードが404に見えても、実リンクは正常なことが多い。実クリックで確認 |
| 8 | 楽天の料率: ダイエット・健康4%、食品4%、家電2%。1商品の報酬上限1,000円、月上限3,000円 |
