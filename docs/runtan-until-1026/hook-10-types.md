# フック「10の型」（教材の特典から要約・ランたん用メモ）

出典：教材の特典note「最初の3行で決まる。バズるフック『10の型』」（2026/10/18に画面収録・スクリーンショットで確認）。既存の投稿案は変更しない。必要なときにアイデア出しで参照する。

| 型 | テンプレ（教材） | ランたんでの使い方の例 |
|---|---|---|
| ①権威借用型 | [有名人・専門家]が言ってた。「[意外な一言]」 ※週1〜2回まで | 実在の発言・公的データのみ。例：スポーツ庁の調査で、30〜40代女性の体力が2001年度より下がっていた |
| ②常識破壊型 | [みんなが信じてること]じゃなくて、[逆の真実]です。 | 痩せたいなら毎日ジム、じゃなくて… |
| ③後悔フック型 | もっと早く知りたかった、〇〇の話する。（過去の自分への手紙が強い） | 20代の自分に教えたい、ロケ弁との付き合い方 |
| ④経験年数＋感情型 | [職業]で[年数]働いていて、忘れられない[瞬間・人]がいます。 | テレビの現場で20年働いていて、忘れられない〇〇がある（実話が必要） |
| ⑤断言＋危機感型 | 断言するけど、〇〇しないと[ヤバい未来]。（損失回避を刺す。やさしいキャラは使いすぎ注意） | 強い口調は業界に対してだけ |
| ⑥共感問いかけ型 | [ターゲット]、[あるあるの状況]いるでしょ？ | 30代から、去年のズボンが入らなくなった人いるでしょ？ |
| ⑦需要確認型 | 〇〇についてまとめたら、欲しい人いますか？ | 待ち時間でできるゆるトレ、まとめたら欲しい人いますか？ |
| ⑧逆張り宣言型 | 批判覚悟で言います。わたし、〇〇なんです。（最後に「同じ人いますか？」。特定の人を下げない） | 批判覚悟で言います。ジムに通わずに体型を保ってます |
| ⑨告白型 | 正直に言います。実は、〇〇なんです。（年数とセットで強い。多用しない） | 正直に言います。運動を始めた理由は健康のためじゃなかった |
| ⑩予告・重要宣言型 | これだけは、知っておいてほしい。（保存されたい投稿と相性が良い） | これだけは知っておいてほしい。現場でもできる運動はある |

## どの型でも守る3原則
1. 答えを最初に書かない（「、」「それは、」で切る）
2. AI感をなくす（「」で誰かのセリフや心の声を入れる）
3. 具体的な数字を入れる

## 手が止まったときの3つの問い
1. 誰の、どんな悩みを刺す？（顔が浮かぶレベルまで絞る）
2. その人が信じてる「常識」は何？（覆すと②になる）
3. 自分が読み手なら、続きを読みたい？（「で？」と思ったら弱い）
