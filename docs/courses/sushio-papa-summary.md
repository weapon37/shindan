## 章ごとの要点
| 章 | 要点 |
|---|---|
| 1 ジャンル選定 | HARMの法則（健康・美容／仕事・副業／恋愛・人間関係／お金・投資）。「悩み×緊急性＝需要」と捉える。HARM外でも、得意・好きなことから始めてよい。絞りすぎると紹介できる商品の幅が狭まる（例: おもちゃのみ→狭い／可愛いもの全般→キャラグッズ、服、バッグ） |
| 2 アカウント作成 | Threadsの作成にはInstagramが必要。名前・画像・紹介文の3つを設定。名前は分かりやすさと呼びやすさ。紹介文は3〜4行以内で端的に。画像はAIで3分で作ってよい。紹介文はThreadsに反映されないので、必ず設定する |
| 3 楽天アフィ登録 | 楽天アカウントがあれば審査なしで開始可。「サイト情報の登録」で、運営サイト名＝Threads、URL＝Threadsプロフィールのシェアリンク、順位＝1位 |
| 4 通常投稿 | いきなりアフィ投稿だけを連投しない。垢BANの基準は非公開で断定できないため、最初の数日は通常投稿から。アフィ開始後も、通常投稿を1日に数回入れる。まず自己紹介、日常やトレンドを気軽に |
| 5 商品選定 | 「自分が紹介したい商品」だけで選ばない。「今その商品に需要があるか」を見る。他の人が紹介している商品で、表示回数が伸びているものから選ぶ。表示回数は投稿を開いて確認。目安は最低でも数千回以上（表示が多い＝必ず売れる、ではない）。同ジャンルで伸びている人を複数見つけておくと時短。投稿文を真似るのではなく、商品と投稿の型を学び、自分で分析する |
| 6 アフィ投稿 | 商品リンクの作り方: 楽天アフィのトップで商品検索→「商品リンク作成」→「SNSリンクを取得」→Threadsアイコンでコピー（URL貼り付けでも作成可）。基本は二段投稿。2段目（リプ欄）にリンクを貼り、必ず「PR」を記載（実例の2段目は「Rakuten PR」＋短縮リンク）。規約を守り、垢BANのリスクも抑える |
| 6 投稿の力点 | 1段目（フック）に全力。最初の1行が最重要で、大げさなくらいでよい。2段目はクリックして初めて見られる。1段目は基本3行以内。伸びたフックはメモに残す。2段目は時間をかけすぎない（商品説明を1行、または「PR＋リンクのみ」もある） |
| 7 投稿後 | 投稿後1〜2時間の反応が重要（著者の体感）。最初の1〜2時間で反応が良い投稿ほど後も伸びやすい。伸びた投稿はスクショ等でストックし、構成や言葉選びを分析する |
| 8 テクニック | アフィ投稿は最強の手札を揃える。伸びた投稿は、数日あけて少し変えて再投稿。表示が取れる間は何度でも少し変えて再投稿し、取れなくなったら手札から外す。表示の取れる商品を大量にストックしておけば、リサーチ時間を削減でき、垢BAN後の新規垢にも使える |
| 8 頻度 | アフィ投稿は1日5〜8回が目安。最低でも5本。多すぎるとBANリスクと伸びにくさ、少なすぎると収益が出にくい。投稿間隔は2時間程度。著者は普段1日6本。お買い物マラソンや0・5のつく日など、収益が出やすい日は8本 |
| 8 時間帯 | 著者の投稿時間: 6時・8時・12時・18時・20時・22時の少し前。早朝・通勤時・昼休み・寝る前を狙う。予約投稿機能（新規スレッド右上の「…」→「日時を指定」）を活用 |
| 9 最後に | 完璧を目指すより、まずやってみる。「投稿→分析→改善」を繰り返す |
