原本: `shirou-threads-monetize-detailed-summary-2026-11-01.pdf`（5ページ、2026-11-01作成。全文はPDFを参照）。
位置づけ: 教材の主張・収益額は、すべて著者・講座生の自己申告で未検証。ランたんで採用するのは「戦術」部分のみ。収益見込みの前提には使わない。

## 教材の主張（要点）
| 章 | 要点 |
|---|---|
| 2. タップ経済 | フォロワー外への露出は、タップ数とプロフィールアクセス数で決まる（いいね・コメント・フォロー周りは、ほぼ関係ないと主張）。1行目の条件は「有益そう」「意外性がある」「続きが気になる」 |
| 3. 投稿の作り方 | STEP1 ネタ（悩み→解決するネタ）／STEP2 1行目に「主張」を書く／STEP3 理由・具体例・補足でつなぐ |
| 投稿数の基準 | フォロワー1万人を目指すなら1日7投稿。新規アカウントの1ヶ月目は毎日7投稿が推奨 |
| 4. マネタイズ3つ | ①アフィリエイト×note（初心者の本命）②高単価商品販売 ③集客代行 |
| 4-1 アフィ | 初心者は楽天でOK。稼ぐ結論は2つ: ①バズらせる ②料率の高い商品を選ぶ |
| 4-2 リスト | note販売の核は「リスト（公式LINE・メルマガ）を集めること」。リストがあれば、アカウントが凍結しても売上を作れる |
| 4-3 黄金ルート | ①アフィ×noteで開始 ②バズらせてアフィ収益を狙いつつ、フォロワーとリストを増やす ③数千フォロワーを超えたら、noteをローンチ |
| 5. AI活用 | 2027年以降はAI活用（Codex、Claude Code等）が生き残り条件、という主張。具体的方法は、オープンチャット誘導で資料は閉じられている |

## ランたんでの採用状況（資料の第6章）
| 区分 | 内容 |
|---|---|
| 採用済み | タップ経済を主指標にする／1日7投稿（11/2から。追加分はリンクなし、アフィ枠は1日2ツリー）／主張型の1行目テスト（R投稿5本、11/1〜11/5の朝枠）／リストの受け皿づくり（公式LINE、11/2に再挑戦予定）／料率の高い商品を選ぶ（afb展開：フィシュル3,300円、筋肉食堂DELI 2,750円、chatFLORA G 16.83%。楽天は料率4%・1件上限1,000円が頭打ち） |
| 意図的に不採用 | 「1ヶ月目でフォロワー1,000人を超えなかったら遅い」（著者の体感。判定に使わない。型の廃止判断はBrain教材の「20〜30本・2〜3週間」を優先）／収益額の主張（計画の前提に置かない）／高単価商品販売・集客代行（現段階は見送り）／note販売（フォロワー数千規模に育ってから検討） |
| 検証中 | 「いいね・コメントは露出にほぼ関係ない」→週次レビューでリプ数を参考値に格下げして様子見／「リストの有無が売上を分ける」→公式LINE開設後に、締めフォローCTA→固定投稿の特典→LINE登録の3点セットで小さく検証 |

## 注意

- 実績数字（年間売上、月7桁など）は、未検証。計画・収益見込みの根拠にしない
