## 自己紹介文（登録用・全文）

はじめまして、タツヤと申します。
テレビ番組の撮影に携わるフリーランスのカメラマンとして、約20年現場に立ってきました。その経験を活かし、YouTube台本やSNS投稿文の作成を行っています。


・現場を知っている台本作り
撮影する側の経験があるため、「読んで面白い」だけでなく「撮れる構成か」「尺に収まるか」「現場で成立するか」まで考えた台本を作れます。冒頭の引き、間の取り方、カットの切り替えなど、映像の流れを前提に構成します。

・スピードと丁寧な仕上げ
構成案から初稿までを速く用意し、言い回しの自然さや事実関係は必ず自分の目で確認してから納品します。「とりあえず形にして見せてほしい」という段階から対応できます。


・YouTube台本（構成案の作成から執筆まで）
・ショート動画（YouTube Shorts／TikTok／リール）の台本
・Threads／Xの投稿文作成
・既存台本のリライト、尺に合わせた調整


ご依頼内容のヒアリング → 構成案のご提示 → 初稿 → ご確認・修正 → 納品、の流れで進めます。
まずは小さな1本からお試しいただけると嬉しいです。

※仮置き・要確定
本業の撮影スケジュールの合間に対応しています。メッセージへの返信は、当日中を心がけています。
